# rftinternship_day6
 Sales Data Analyzer

A simple Python project to analyze sales data from a CSV file.

## Features
- Read CSV data
- Calculate total sales per product
- Find total revenue
- Find top-selling product
- Add TOTAL column (Quantity × Price)
- Sort products by revenue

## Technologies Used
- Python
- CSV Module

## Dataset

```csv
PRODUCT,QUANTITY,PRICE
A,2,100
B,1,200
A,3,100
C,5,50
``
